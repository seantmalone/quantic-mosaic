# Global constraints (binding for every phase; copied from the spec)
- Python 3.12 (uv-managed; `.python-version` = 3.12.14; `python:3.12-slim` in Docker). `pyproject.toml` authoritative; `requirements.txt` generated by `uv pip compile` and committed; exact version pins everywhere.
- `mcp` pinned to 2.2.0 and written against the 2.x API: `from mcp.server.mcpserver import MCPServer`, `streamable_http_client`, 2-tuple client yield, snake_case fields (`server_info`, `input_schema`, `structured_content`).
- fastembed 0.8.0, `BAAI/bge-small-en-v1.5`, `batch_size=8`, `threads=1`, never `parallel=`; `rag/embed.py` is the only call site; model cache under `.cache/fastembed` (`FASTEMBED_CACHE_PATH`).
- sqlite-vec 0.1.9 `vec0` (cosine) + FTS5, one read-only index file `data/index/hr_index.sqlite`; committed `data/index/chunks.manifest.jsonl`; `.gitignore` carries `data/index/*` and `!data/index/chunks.manifest.jsonl` literally.
- One trace writer: only `core/trace.py` inserts into sessions/turns/spans (grep-enforced in `tests/architecture/test_conventions.py`); `mock_writes` written only by `mcpserver/**`; `confirmations` minted only in `web/`.
- Real wall clock everywhere; no clock module, no NOW_OVERRIDE; mock data computes against its `as_of: 2026-09-01` snapshot.
- Agent model pinned: Anthropic `claude-haiku-4-5` via the native `AnthropicAdapter` (anthropic SDK 1.x: no `temperature` kwarg — use `extra_body={"temperature": 0}`; tools NOT declared strict; `output_config.format` for constrained JSON; one `cache_control` ephemeral breakpoint on the last system block; 4096-token cache floor). Judge and failover: Gemini `gemini-3.5-flash-lite` via `OpenAICompatAdapter`. `StubAdapter` in CI. No Groq anywhere. Any other Anthropic model requires Sean's explicit approval.
- Access gate: `APP_ACCESS_TOKEN` via `?access=` → cookie `mosaic_access` (HttpOnly, SameSite=Lax, Secure on https) with a redirect that strips the parameter, or `Authorization: Bearer`; open routes: `/health`, `/ready`, `/static/*`, `/access`. Personas: cookie `mosaic_actor` or header `X-Actor` (`E1xxx` or `admin`, default E1042); dashboard, `/api/*`, write controls, smoke eval and privileged `/chat` options require admin → 403 `{"code":"ADMIN_REQUIRED"}`.
- Secrets only from the environment through `settings.py`; `.env` is git-ignored and must never be read aloud, printed, or committed; `.env.example` carries no real values; redaction covers `sk-ant-`, `sk-`, `AIza` patterns and every env value whose key ends `_KEY`/`_TOKEN`/`_SECRET`.
- Every failure path answers HTTP 200 with a useful body; `/health` always 200 (`status: ok|degraded`), `/ready` 503 until model + index resident; exactly five `degradations[]` strings.
- CI: one workflow `.github/workflows/ci.yml`; jobs `lint`, `test` (stub LLM, whole suite `pytest -q`), later `docker` and `deploy` (`needs: [test, docker]`, main pushes only, curl `RENDER_DEPLOY_HOOK_URL`); `on: push [main]`, `pull_request`, `workflow_dispatch(deploy_only)`; `paths-ignore` for `evaluation/results/**`, `evaluation/REPORT.md`, `docs/**`, `'*.md'` (ratified 2026-09-09 to match spec §15.1: a GitHub path filter's `*` does not cross a `/`, so `'*.md'` ignores repo-root docs only and `corpus/**` stays gated for `scripts/check_facts.py` from P2 onward; `*.md` (repo-root markdown only, so corpus/** stays gated) would have un-gated every corpus edit). Push path is keyless and offline after the model cache fill.
- Tests: pytest; output pristine (no warnings); tests verify behaviour, not mocks; every definition-of-done command in the phase brief must pass with real output pasted in the report.
- Commit message pattern: `P<n>(<scope>): <what landed>` + bullets + `Gate: <commands> — green` + `Reqs: <ids>` + the two attribution lines (`Co-Authored-By: <the committing session's own model, named exactly as its harness names it> <noreply@anthropic.com>` and `Claude-Session: https://claude.ai/code/session_01RnJs3hSPUc8kca4BtF5oAM`). **Amended 2026-09-11** (ruling in `progress.md`): the `Co-Authored-By` trailer names the model that wrote the commit, not a fixed string — which is what the history has done since P0. Of 146 commits, 113 carry `Claude Opus 5 (1M context) <noreply@anthropic.com>` (every phase commit, written by an implementer or reviewer subagent), 30 carry `Claude Fable 5.1 <noreply@anthropic.com>` (the coordinating session's own commits) and three are branch merges with no trailer. Where a session harness instruction names the trailer, that instruction is authoritative and this line follows it. One convention, one rule: never co-author a commit to a model that did not write it. Fix-ups: same scope with a `fix:` prefix on the subject.
- Repo layout, endpoints, tool names, env var names, table columns and page routes are exactly those in the spec; never invent components.
