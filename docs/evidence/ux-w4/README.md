# UX W4 — numbers, jargon and dashboard cleanup

Every dashboard route, before and after, captured by `make ux-capture` against the stub app at
1440×900 (`LLM_PROVIDER=stub`, loopback only — no live model call and no request to the deployed
URL). `before-*` is commit `42ca1fe`, the base the wave started from; `after-*` is this branch.

* `*-1440.png` — the screen **as painted at the fold**, which is the comparison a reader makes.
* `*-1440-full.png` — the whole page, kept for the two pages whose change is mostly below the fold:
  `tools` (JSON cells → one-line summaries with a disclosure) and `session-demo1` (the waterfall's
  axis, the instants drawn as ticks, the named payload disclosures).
* `*-390.png` — the phone, where a 13-column table becomes a stack of cards.

The full set — 51 screen ids × 3 viewports, with the `.txt` DOM dumps, `.numbers.json` and
`.overflow.json` the audit used — is regenerated by `make ux-capture` into the git-ignored
`.ux-capture/`. This directory carries only what the report cites.

What to look for, page by page:

| Pair | The defect it shows, and the fix |
|---|---|
| `overview` | 17 equal-weight tiles with no reading order → 12 in three labelled groups; `$0.0000` ×3 → one spend tile with today / 7-day sub-lines; an error rate with no denominator → `20.0%` above `1 of 5 turns`; a percentile with no sample → its `n`; a provider line, so `$0.00` reads as a recorded-script run and not a broken meter |
| `sessions`, `turns` | a 32-hex id as the first and widest column → the human column first and the id an 8-character chip at the end; `AUTH_MODE` / `ACTOR_ROLE` → Sign-in / Role |
| `tools` | `create_mock_hr_ticket` at a **50.0% error rate** — the counted error was the confirmation gate working → `0.0% (0 of 2 calls)` and a `Paused for confirmation` column; JSON clipped mid-token in two columns → one-line summaries with the raw arguments one disclosure below |
| `session-demo1`, `deeplink-session-turn1` | `Guardrail hits 0` above seven guardrail spans → **blocks** beside a new **checks** count; one flattened wall of answer text → the typed blocks the turn stored; a waterfall with no axis, no total and 2px bars for instants → a quarter-tick axis, a total, and ticks |
| `llm`, `retrieval` | `TTFB` / `Cache hit` / `Limiter wait` / `k` / `k source` / `Max dense` → English labels with definitions on hover; `0 ms` on every row → `<1 ms`; a ragged left-aligned score → two decimal places, right-aligned |
| `safety` | six bare letters on a chart axis with a silently missing rule → all six named, zero bars included; an irreversible **Reset sandbox** above the evidence it destroys, in solid red, with no confirmation → below the table, demoted, behind `hx-confirm`, disabled when empty |
| `mcp` | a `CATALOG SHA [REDACTED]` column and `0 ms` on all six history rows → the column dropped and the card labelled **Last live handshake** |
| `corpus`, `corpus-doc` | `PAGES 3.8` for a markdown file → **Words**; 32-character chunk ids as section headings over a 4,887px dump → the heading path first, the id a chip, offsets labelled, bodies collapsed behind a contents list |
| `evals`, `eval-run` | `GROUNDEDNESS_MEAN 0.9839181286549706` → **Groundedness 98.4%**; "Headline metrics" that could not be joined to "Runs" → the run's label and date as its link text; no verdict and no methodology → *"21 of 28 items passed (75.0%)"*, the previous run of the same variant beside it, and the dataset legend |
