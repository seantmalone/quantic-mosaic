## 2. Remaining defects by cause — smallest fix each

| cause | scenarios | smallest fix |
|---|---|---|
| **Engine called with the wrong arguments** — `days` instead of `duration_days`; a follow-up that bumps `days` but reuses the old `end_date` | 13, 9 | Validate compliance `parameters` against the scenario's rule schema: reject unknown keys and reject `days` that disagrees with `start_date`/`end_date` as an argument error instead of returning `not_stated` rows |
| **`not_stated` rows still reasoned over, and the remediation misfires** — conclusions denying roles the engine required; "I could not check X" printed on a met row, naming the wrong requirement | 13 | Make the C05 rewrite quote the row id it is rewriting (so it can only fire on that row's own subject), and forbid any sentence denying a role present in `approvals_required` |
| **Policy shipped as non-policy advice** — mandatory corpus rules and engine `next_steps` under "Recommendation — not company policy" | 1, 7, 15 | Type by provenance: a block entailed by a citation or by an engine `next_step` is `policy_fact`; reserve `recommendation` for blocks with neither |
| **Verdict never stated** — yes/no questions answered by stacked requirement rows | 1, 2, 3, 5, 15 | Emit a deterministic first block from `verdict` + `unmet` before synthesis blocks on any yes/no workflow question |
| **Approver rendering residue** — resolved approvers left as "your director"; `self_approval_routed` pinned to the wrong role; skip-level unnamed | 1, 3, 7, 14, 16 | At render time substitute every `approvals_required` role with its `approvers[]` name, and attach the routing sentence only to the row whose `self_approval_routed` is true |
| **Write state vs prose** — HR ticket described as a MosaicOne submission; routing/submission asserted in the past or present tense when nothing was written | 3, 4, 6, 16 | Derive the performed sentence and the routing mood from the tool result (`status`, `queue`, `ticket_id`): no `created` ⇒ conditional mood, and no approval-chain sentence at all on a turn with no request |
